# Portfólio — Geovanne Augusto

Site pessoal em HTML, CSS e JavaScript, com projetos, habilidades, interesses e contato.

## Executar no PC

Com Node.js instalado, abra um terminal nesta pasta e execute:

```sh
npm start
```

Acesse **http://localhost:3000/**. Não é necessário instalar dependências.

Também é possível abrir `index.html` diretamente; a cópia de e-mail depende das permissões do navegador e funciona melhor em localhost ou HTTPS.

## Organização

- `index.html`: conteúdo e estrutura.
- `style.css`: visual responsivo, temas e preferências de movimento.
- `translations.js`: textos originais em português e inglês.
- `app.js`: controles, traduções adicionais, filtros, temas, navegação e cópia de e-mail.
- `Fotos/`: foto e capturas reais dos projetos.
- `server.js`: servidor local para desenvolvimento.

Os links que ainda não possuem destino aparecem como “em breve”. Para disponibilizá-los, substitua o respectivo `<span>` por um link válido em `index.html`.

As fontes do Google são opcionais: o site usa fontes do sistema quando elas não carregam. Os ícones e controles funcionam sem serviços externos.
